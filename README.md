# 🎮 Nostalgia Hub — Y2K Retro Gaming Platform

Статичный веб-интерфейс игрового хаба в стиле веб-дизайна 2000-х годов (Y2K / Classic Web).

## 🚀 Особенности
- **Retro Visual Style**: Тёплая палитра, пиксельные шрифты (`Press Start 2P`, `VT323`), классические рамки и тени.
- **Модульная структура**: Страницы `HOME`, `SERVERS`, `COMMUNITY` и `BLOG`.
- **Полная адаптивность**: Поддержка ПК и мобильных устройств.
- **Чистый stack**: Нативный HTML5 и CSS3 без сторонних тяжелых фреймворков.

## 🛠 Технологии
- HTML5 / CSS3 (Flexbox & Grid)
- Google Fonts (`Press Start 2P`, `VT323`)
